# Анализ загруженности парковки ТЦ

Интеллектуальная система автоматического определения занятости парковочных мест
по изображению с видеокамеры на основе нейросетевой модели **YOLOv8**,
с сохранением истории замеров и **генерацией аналитических отчётов**
в форматах PDF, Excel и CSV.

Проект выполнен в рамках производственной практики
(Системы искусственного интеллекта), МТУСИ, кафедра «Программная инженерия».

---

## Возможности

| Возможность | Описание |
|---|---|
| Детекция транспорта | YOLOv8n (COCO): классы `car`, `truck`, `bus`, `motorcycle` |
| Анализ занятости | Сопоставление рамок детекции с размеченными местами (ROI) по доле перекрытия |
| Визуализация | Занятые места — красным, свободные — зелёным, сводка на кадре |
| История замеров | База данных SQLite: парковки, места, замеры, статусы мест |
| Аналитика | Средняя загруженность по часам суток и по дням периода |
| **Генерация отчётов** | **PDF с графиками и таблицами, Excel из 4 листов с диаграммой, CSV** |
| Веб-интерфейс | Bootstrap 5 + Chart.js: загрузка кадра, статистика, выгрузка отчётов |
| REST API | FastAPI с автодокументацией Swagger UI |

## Установка

```bash
git clone https://github.com/<ваш-аккаунт>/parking-occupancy-ai.git
cd parking-occupancy-ai

python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

pip install -r requirements.txt
```

Веса `yolov8n.pt` загружаются библиотекой Ultralytics автоматически
при первом запуске детектора.

## Запуск

```bash
python database.py          # создание таблиц и наполнение демо-данными
python app.py               # запуск сервера
```

- Веб-интерфейс: <http://localhost:8000>
- Документация API (Swagger UI): <http://localhost:8000/docs>

Генерация отчётов без запуска сервера:

```bash
python report_generator.py  # создаст PDF, XLSX и CSV в каталоге reports/
```

## REST API

### Анализ и аналитика

| Метод | Эндпоинт | Описание |
|---|---|---|
| POST | `/api/analyze` | Анализ загруженности по загруженному изображению |
| GET | `/api/result/{detection_id}` | Обработанное изображение с разметкой мест |
| GET | `/api/lots` | Список парковок |
| GET | `/api/history` | История замеров загруженности |
| GET | `/api/stats/hourly` | Средняя загруженность по часам суток |

### Генерация отчётов

| Метод | Эндпоинт | Описание |
|---|---|---|
| GET | `/api/report/preview` | Предпросмотр содержимого отчёта без выгрузки файла |
| GET | `/api/report/pdf` | Формирование и выгрузка PDF-отчёта |
| GET | `/api/report/xlsx` | Формирование и выгрузка отчёта Excel |
| GET | `/api/report/csv` | Выгрузка замеров в CSV |
| GET | `/api/reports` | Журнал ранее сформированных отчётов |

Параметры отчётов: `lot_id`, `date_from`, `date_to` (формат `ГГГГ-ММ-ДД`).
Если период не указан, отчёт формируется за последние 7 суток.

Пример:

```bash
curl -o report.pdf "http://localhost:8000/api/report/pdf?lot_id=1&date_from=2026-06-23&date_to=2026-07-06"
```

## Состав отчётов

**PDF** (ReportLab + Matplotlib) — 6 разделов:
сводные показатели за период, график загруженности по часам суток,
диаграмма по дням, детализация по дням, использование каждого места,
выводы и рекомендации.

**Excel** (openpyxl) — 4 листа:
`Сводка` (KPI), `Замеры` (все замеры с формулой среднего),
`По часам` (данные и линейная диаграмма), `По местам` (частота занятости).

**CSV** — выгрузка замеров в кодировке `utf-8-sig`
(корректно открывается в Microsoft Excel), разделитель `;`.

## Схема базы данных

| Таблица | Назначение |
|---|---|
| `ParkingLots` | Парковки: название, расположение, общее число мест |
| `Spaces` | Размеченные места с координатами области (ROI) |
| `Detections` | Замеры: время, занято, свободно, процент загруженности |
| `SpaceStates` | Статус каждого места в рамках замера |
| `Reports` | Журнал сформированных отчётов |
